# Полка

Приложение для компьютера (Windows) и телефона (Android): прочитанные книги и просмотренные фильмы и сериалы.
Обложки книг и постеры подтягиваются сами. Оформление — как у «Кармана».

В Claude: [макет](https://claude.ai/artifact/CE91rsVevVhjwaViVnEVCW),
[план](https://claude.ai/artifact/JJyRNd7Bh3PnWkg2wj5g6R) и [демо интерфейса](https://claude.ai/artifact/XoMxto4XTs8ZPGfMtZPkg5)
на примерных данных.

## Что сейчас готово

**Версия 0.1.0** — первая сборка: этапы 1, 2, 3 и 5 плана в коде. На устройствах ещё не проверялась,
ответы каталогов — тоже (из облачной среды Claude они закрыты).

- **Полка и лента:** обложки сеткой или лента по месяцам; «Всё», «Книги», «Кино и сериалы»; блок «Сейчас»
  с быстрыми действиями («+1 серия», «Готово»); строка цели года.
- **«Хочу»:** отложенное, с кнопкой «Начать».
- **Добавление книги:** поиск по названию, автору или ISBN сразу в FantLab, Google Books и Open Library;
  обложка на выбор из разных изданий, своё фото или без обложки. На телефоне — скан штрихкода ISBN,
  на компьютере ISBN вводится в поиск. По ссылке на страницу книги или фильма. Вручную — если нигде нет.
- **Фильмы и сериалы** через ПоискКино (ключ в настройках): постер, год, режиссёр, жанры, рейтинги
  Кинопоиска и IMDb, описание, сезоны и серии.
- **Карточка:** Хочу / В процессе / Готово / Брошено с датами, оценка 1–10, заметка, свои метки, формат
  (бумажная, электронная, аудио), страницы или часы, другая обложка. Сериал раскрывается по сезонам,
  серии отмечаются по одной или сезоном, статус идёт следом.
- **Итоги года:** цель (отдельно книги и кино) и темп, по месяцам, страницы и часы, жанры, авторы, оценки,
  лучшее за год.
- **Настройки:** расцветки и тема из «Кармана», цель года, ключи ПоискКино и Google Books.
- **Данные:** зашифрованная база (SQLCipher), ключ — в хранилище системы (DPAPI в Windows, Keystore в Android).
  Обложки лежат в базе, а не ссылками: видны без интернета и не пропадут, если сайт уберёт картинку.
  Журнал изменений для будущего обмена между устройствами уже ведётся.

**Резервные копии** (0.2.0, [docs/stage-4.md](docs/stage-4.md)): все записи и обложки в одном файле,
зашифрованном паролем копии; автокопии на компьютере каждый день или раз в неделю в выбранную папку
(например, Яндекс Диска), «Сделать копию» по кнопке; восстановление на компьютере и на телефоне —
записи добавляются к нынешним.

**Обмен по Wi-Fi** (0.3.0, [docs/stage-4.md](docs/stage-4.md)): устройства в одной сети связываются один раз
по коду из восьми знаков или QR-коду и дальше обмениваются сами — записи и обложки; чужим в сети «Полка»
не отвечает. Устроено как в «Кармане» 0.15, со своими портами.

**Обмен через облако** (0.4.0, [docs/stage-4.md](docs/stage-4.md)): Яндекс Диск по паролю приложения
или свой сервер WebDAV. В облаке — только зашифрованные файлы в папке «Полка», открыть их можно только
паролем копий; Wi-Fi и облако работают вместе.

**Поиск, «Поделиться» и картинка года** (0.5.0, [docs/stage-6.md](docs/stage-6.md)): лупа и порядок
по автору, жанру, году или метке в шапке полки; «Поделиться» → «Полка» на Android открывает добавление
по ссылке (Кинопоиск — через ПоискКино); итог года картинкой — сохранить или отправить.

Пока нет: повторного прочтения, PIN-кода, ИИ.

Как проверить обложки — [docs/stage-0.md](docs/stage-0.md). Что проверить в приложении — [docs/stage-1.md](docs/stage-1.md).

## Как устроено

```
crates/polka-core/    ядро на Rust: записи, статусы и даты, сериалы по сериям, итоги года, ISBN,
                      каталоги (Open Library, Google Books, FantLab, ПоискКино, страница по ссылке),
                      база SQLCipher с журналом изменений и обложками, резервные копии,
                      обмен по Wi-Fi (связь по коду, поиск в сети), обмен через облако
                      (зашифрованные файлы записей и обложек), проверка обложек (examples/)
crates/polka-cloud/   облако: Яндекс Диск и свой сервер по WebDAV, имитация сервера для проверок
crates/polka-secure/  ключ базы в хранилище системы (DPAPI, Android Keystore) — как в «Кармане»
app/                  приложение Tauri 2: интерфейс (React) и мост к ядру (src-tauri)
scripts/              донастройка Android-проекта при сборке
.github/workflows/    проверки, проверка обложек и сборки
docs/                 списки для проверки обложек, что проверить
```

Одно ядро на Rust работает и на Windows, и на Android; интерфейс — веб-страница внутри приложения.

Поиск книги идёт по трём каталогам одновременно. Одна и та же книга из разных каталогов склеивается
в одну строку, а обложки всех её изданий попадают в выбор. Выбранная обложка скачивается, проверяется
(настоящая картинка, не заглушка) и хранится в базе по отпечатку SHA-256.

## Сборки

Каждый пуш запускает «Сборки» в Actions — как у «Кармана». Готовые файлы — в разделе Artifacts у запуска:

- `polka-windows` — установщик `.exe` и `.msi`;
- `polka-android` — `.apk` для телефона. С секретами `ANDROID_KEYSTORE` и `ANDROID_KEYSTORE_PASSWORD`
  он подписан постоянным ключом и обновляется поверх, без них — отладочная сборка. Псевдоним ключа — `polka`;
  подойдёт и ключ «Кармана», если добавить секрет `ANDROID_KEY_ALIAS` со значением `karman`.

«Проверки» запускают тесты ядра и моста, сборку интерфейса и поиск известных уязвимостей в библиотеках.
Проверка обложек — там же: после каждого пуша в main и вручную (**Actions → Проверки → Run workflow**).
Для фильмов ей нужен секрет `POISKKINO_KEY`, ключ Google Books (`GOOGLE_BOOKS_KEY`) — по желанию.

## Разработка

Нужны Rust, Node.js 22, для Android — Android Studio с NDK.

```bash
cargo test -p polka-core           # тесты ядра
cargo test -p polka-app            # тесты моста (нужен собранный интерфейс: cd app && npm run build)
cd app && npm ci
npm run dev                        # интерфейс в браузере на демо-данных
npm run tauri dev                  # приложение на компьютере
npm run tauri android dev          # на телефоне по USB
```

## План

1. **Этап 0** — проверки и макет: макет готов; программа проверки обложек готова и ждёт запуска с компьютера.
2. **Этап 1** — основа и книги: полка и лента, «Хочу», поиск, выбор обложки, своё фото, карточка (готово в коде).
3. **Этап 2** — штрихкод и ссылка (готово в коде).
4. **Этап 3** — кино: ПоискКино, постеры, рейтинги, сериалы по сериям (готово в коде).
5. **Этап 4** — обмен и копии: резервные копии по выбору в настройках (готово, 0.2.0), обмен по Wi-Fi по коду
   с обложками (готово, 0.3.0), обмен через Яндекс Диск или свой сервер WebDAV (готово, 0.4.0).
6. **Этап 5** — итоги года (готово в коде).
7. **Этап 6** — поиск по полке и порядок по автору, жанру, году или метке, «Поделиться» → «Полка» на Android,
   итог года картинкой (готово, 0.5.0).
8. **Позже** — ИИ (запись фразой, книга по фото обложки), забавные сравнения времени, PIN-код, профили.

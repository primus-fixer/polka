# Этап 0: проверка обложек

Главное требование «Полки» — обложки подтягиваются сами. Перед проверкой приложения на устройствах
стоит узнать, как часто каталоги их находят. Программа `cover_check` прогоняет список книг по FantLab,
Google Books и Open Library так же, как приложение, и скачивает найденную обложку — считается только
картинка, которая на самом деле скачалась.

**Цель:** обложка нашлась и скачалась минимум у 8 книг из 10. Если русские книги находятся заметно хуже,
до следующих этапов решаем, какой каталог добавить.

Списки — [cover-check-books.txt](cover-check-books.txt) (15 русских и 15 английских книг) и
[cover-check-films.txt](cover-check-films.txt) (10 фильмов и сериалов). Можно заменить своими:
строка — «Название — Автор», фильм — «Название (год)».

## Как запустить

Из облачной среды Claude каталоги закрыты, поэтому проверка идёт с вашего компьютера или в GitHub.

**В GitHub** — проще всего, ничего ставить не нужно. Проверка запускается сама после каждого пуша в main.

1. Добавьте секреты (**Settings → Secrets and variables → Actions**): `POISKKINO_KEY` — для фильмов и, по желанию,
   `GOOGLE_BOOKS_KEY`: из сети GitHub Google отвечает и без ключа. Где взять ключи — в [stage-1.md](stage-1.md).
2. **Actions → Проверки → Run workflow.** Через несколько минут итог появится на странице запуска,
   а отчёт с картинками — в **Artifacts** (`cover-report`).

**На компьютере** — нужен Rust ([rustup.rs](https://rustup.rs)):

```bash
cargo run -p polka-core --example cover_check -- docs/cover-check-books.txt
# с фильмами — ключ ПоискКино из Telegram-бота @poiskkinodev_bot:
POISKKINO_KEY=ваш-ключ cargo run -p polka-core --example cover_check -- docs/cover-check-books.txt docs/cover-check-films.txt
```

В Windows (PowerShell) ключ задаётся так: `$env:POISKKINO_KEY="ваш-ключ"`, затем та же команда.
Ключ Google Books задаётся так же — `GOOGLE_BOOKS_KEY`. Он нужен, если Google отвечает «квота исчерпана»:
без ключа так бывает из некоторых сетей.

**Через Claude** — откройте этот чат в приложении Claude на компьютере и напишите «запусти проверку
обложек»: если на компьютере установлен Rust, Claude запустит её сам и разберёт отчёт.

Проверку стоит запускать из обычной сети. Из сети, где закрыты сайты в зоне .ru, FantLab не откроется,
а обложки Open Library не скачаются: их отдаёт archive.org. Так было при первом прогоне 14 ноября.

## Как читать итог

```
Обложка скачалась: 26 из 30 книг (87%)
  русские издания: 12 из 15
  на английском:   14 из 15
  FantLab: варианты обложки у 13 книг
  …
Постер скачался: 10 из 10 фильмов и сериалов
Цель этапа 0 (обложка минимум у 8 книг из 10): выполнена
```

Цифры здесь — пример. Рядом появятся `cover-report.html` (у каждой книги — найденные обложки
и источник) и `cover-report.json`. Пришлите итог и отчёт, если цель не выполнена: по отчёту видно,
какой каталог что вернул.

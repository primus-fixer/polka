# Этап 18: протокол обмена — из общего модуля (0.11.6)

## Что изменилось

Для человека — ничего: связь по коду, обмен по Wi-Fi со связанными устройствами, обложки и файлы книг — как раньше.
Внутри протокол обмена больше не лежит в «Полке» своей копией, а берётся из общего модуля
[kit](https://github.com/primus-fixer/kit) 0.8.0 (`kit_core::sync`) — того же, на который переходит «Карман»:
приветствие с версиями журнала, пачки событий, круги обмена обложками и файлы книг кусками с докачкой.
Передача файлов кусками в kit больше не привязана к книгам — она пригодится «Мосту».

## Как устроено

- `polka-core/src/sync.rs` — то, чем «Полка» отличается: её журнал для протокола (база отдаёт и принимает
  события, обложки и куски файлов книг), настройки обмена (поля `files` нет, файлы книг — с 0.8.0) и прежний
  отчёт обмена с числом файлов книг.
- Шифрованный канал Wi-Fi (`lan.rs`) отдаёт протоколу байты: сообщения — те же, что раньше, байт в байт.

## Как проверено

- Все проверки ядра, в том числе связь двух устройств по коду и обмен по ключу пары с обложками и файлами книг.
- Настоящие программы прежней «Полки» (0.11.5) и новой: прежняя ждёт по коду, новая подключается — и наоборот.
  В обе стороны прошли связь по коду, первый обмен записями и обложкой и обмен по ключу пары.
- В проверках kit: сообщения — те же байты, что у обоих приложений до kit; файлы кусками докачиваются с места
  обрыва; со старой «Полкой» (до 0.8.0) файлы книг не передаются; вложения с неверным отпечатком не сохраняются.

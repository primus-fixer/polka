# Этап 19: связь по Wi-Fi — из общего модуля (0.11.7)

## Что изменилось

Для человека — ничего: поиск устройств в сети, связь по коду и обмен по Wi-Fi со связанными устройствами — как раньше.
Внутри всё устройство связи больше не лежит в «Полке» своей копией, а берётся из общего модуля
[kit](https://github.com/primus-fixer/kit) 0.9.0 (`kit_core::lan`) — того же, на который переходит «Карман»:
код связи и общий ключ из него (SPAKE2), ключ пары, шифрованный канал сеанса и поиск в сети.

## Как устроено

- `polka-core/src/lan.rs` — настройки «Полки» (`LAN`): порты 47510 и 47511, метки `PLKL`/`PLKQ`/`PLKA`,
  имена сторон и личная строка ключей `polka-lan`. У «Кармана» — свои, поэтому приложения в одной сети
  не мешают друг другу. Здесь же — прежний отчёт обмена с числом файлов книг и прежние тексты ошибок.
- `polka-core/src/pairing.rs` — QR-код связи «Полки»; код из восьми знаков и проверка адреса домашней сети — из kit.
- `polka-core/examples/lan_peer.rs` — второе устройство для сквозных проверок: своя база и команды
  (записать книгу с обложкой, ждать с кодом, связаться, обменяться, искать в сети).

## Как проверено

- Ключи выводятся как раньше: проверка на тех же значениях, что в 0.11 (и в kit — на значениях обоих приложений).
- Все проверки ядра: связь по коду, обмен по ключу пары с обложками и файлами книг, пять неверных кодов,
  подставное устройство без кода, чужие запросы, поиск в сети только для связанных и при показанном коде.
- Настоящие программы прежней «Полки» (0.11.6) и новой, все четыре сочетания (кто ждёт с кодом, кто связывается):
  поиск при показанном коде, неверный код («Осталось попыток: 4»), связь по коду с первым обменом записями
  и обложками, обмен по ключу пары, поиск связанного устройства. Ответы одинаковые, отличается только
  номер версии.

# Этап 13: вход и ключ базы — из общего модуля (0.11.1)

## Что изменилось

Снаружи — ничего. Внутри «Полка» больше не держит свою копию кода, который у неё и у «Кармана» совпадал
построчно: ключ базы в хранилище системы (DPAPI на Windows, Android Keystore на телефоне), Windows Hello,
PIN-код с паузами после ошибок и вход с автоблокировкой. Теперь это общий модуль
[kit](https://github.com/primus-fixer/kit) версии 0.1.0; исправления в нём достаются обоим приложениям.

База, ключ, PIN-код, пароль облака и связанные устройства остаются прежними: строки, которыми ключи
привязаны к «Полке», не менялись, и это закреплено проверкой.

## Как устроено

- Зависимости `kit-core`, `kit-secure`, `kit-tauri` — на коммит версии 0.1.0 (`app/src-tauri/Cargo.toml`);
  когда у kit появится метка `v0.1.0`, ссылка заменяется на метку.
- `app/src-tauri/src/names.rs` — чем «Полка» отличается от других приложений на модуле: название в трёх
  падежах и строки ключей. **Строки ключей менять нельзя.**
- Вход — `kit_tauri::guard`: «Полка» создаёт `Lock` при запуске, отдаёт ему местные настройки базы
  (`StoreMeta`) и говорит, что делать при блокировке (убрать показанный код связи) и при возврате
  в окно (обменяться с облаком).
- Удалены `crates/polka-secure`, `polka-core::pin` и `app/src-tauri/src/guard.rs`.
- Проверку ключа в DPAPI на Windows теперь делает сам модуль: в его проверках ключ, защищённый так,
  как это делала «Полка» до 0.11.1, открывается модулем, и наоборот.

## Что проверить

Обновлять поверх 0.11.0, ничего не удаляя.

| Где | Что сделать | Что должно получиться |
|---|---|---|
| Компьютер | Обновить до 0.11.1, открыть «Полку» | Полка на месте: те же книги, обложки, настройки |
| Компьютер | С PIN-кодом: открыть «Полку», ввести PIN | Вход как раньше; неверный PIN — «Неверный PIN-код», после пяти ошибок — пауза |
| Компьютер | Настройки → Вход → включить Windows Hello, заблокировать, войти через Hello | Запрос Windows Hello поверх окна «Полки», вход проходит |
| Компьютер | «Забыли PIN?» | Подтверждение через Windows Hello, затем можно задать новый PIN |
| Компьютер | Свернуть «Полку» больше чем на 5 минут и вернуться | Экран входа |
| Телефон | Обновить до 0.11.1, открыть «Полку» | Полка на месте |
| Телефон | Вход по отпечатку; «Забыли PIN?» | Отпечаток работает; сброс — через блокировку экрана телефона |
| Компьютер и телефон | Настройки → Облако → «Обменяться сейчас» | Обмен проходит без повторного ввода пароля |
| Компьютер и телефон | Настройки → Обмен по Wi-Fi → «Обменяться» у связанного устройства | Обмен проходит, связывать заново не нужно |
| Компьютер | Показать код связи и заблокировать «Полку» | Код отменён: после входа его нужно показать заново |

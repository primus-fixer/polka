# Этап 11: коннектор для приложения Claude (0.10.0)

«Полка» на компьютере подключается к приложению Claude как расширение — так же, как «Карман».
В разговоре с Claude можно спрашивать о прочитанном и просмотренном, а если разрешить запись — просить
добавить книгу, поставить оценку или отметить серии.

Примеры:

- «Что я прочитал в этом году и что понравилось больше всего?»
- «Посоветуй, что взять из „Хочу“ на выходные — что-нибудь покороче».
- «Сколько я в этом году провёл за книгами и у экрана? Успеваю к цели?»
- «Найди цитаты про море».
- «Я дочитал „Щегла“, поставь 9 из 10 и метку „отпуск“».
- «Добавь в „Хочу“ „Зулейха открывает глаза“ Гузели Яхиной».
- «Отметь, что я посмотрел третий сезон „Во все тяжкие“».

Claude внутри самой «Полки» (по ключу API: запись фразой, книга по фото обложки) решено не делать:
разговор идёт в приложении Claude, по вашей подписке, ключ API не нужен.

## Как подключить

1. В «Полке» на компьютере: **Настройки → Claude** → включите «Подключение для Claude». Запись —
   отдельным переключателем «Разрешить запись».
2. Там же — **«Установить в Claude»**: в «Загрузках» появится файл «Полка для Claude.mcpb», и он сразу
   откроется — приложение Claude предложит установить расширение. «Сохранить файл расширения» — то же
   без открытия; установить можно и в приложении Claude: Настройки → Extensions → Advanced settings →
   Install Extension… и выбрать файл.
3. Спросите Claude о полке. Если «Полка» закрыта, она откроется сама.

Если расширение не ставится, в «Полке» есть **«Ручная настройка»**: готовый текст для файла настроек
приложения Claude (`claude_desktop_config.json`, Настройки → Developer → Edit Config) — скопируйте его
и перезапустите приложение Claude.

## Что Claude может

**Читать** (когда подключение включено):

- сводку: сколько книг, фильмов и сериалов в каждом статусе, итоги этого года и цель, что сейчас читается
  и смотрится (с процентом прочитанного и следующей серией), последние законченные, метки;
- полку с отбором и поиском: вид, статус («Хочу»), текст, метка, жанр, автор или режиссёр, год, оценка;
- одну запись подробно: даты, оценка, заметка, жанры, описание, серии по сезонам, место в читалке,
  сколько цитат и закладок, есть ли файл книги;
- итоги любого года: книги, фильмы, сериалы и серии, страницы, часы за книгами, у экрана и в читалке,
  по месяцам, частые жанры и авторы, лучшие книга и фильм;
- цитаты из читалки с заметками — все или по одной книге, с поиском.

**Записывать** (только если «Разрешить запись» включено):

- добавить книгу, фильм или сериал — с проверкой, что такого ещё нет на полке. «Полка» сама ищет
  в каталогах (тех же, что в «Добавить») обложку, год, жанры, страницы и сезоны: берёт то же
  произведение — то же название и, если автор назван, та же фамилия; не нашлось — запись без обложки,
  её можно выбрать в карточке;
- изменить запись: статус (даты — как в «Полке»), оценку, заметку, метки, формат книги, поправить
  название, авторов, год;
- отметить серии сериала: списком, с первой по N-ю или весь сезон; статус следует за сериями сам;
- удалить запись (цитаты, закладки и файл книги остаются);
- цель на год.

Каждое действие Claude «Полка» показывает сообщением с кнопкой **«Вернуть»**, а в Настройки → Claude —
списком «Последние действия Claude» с кнопкой «Отменить». Отменить нельзя, если после Claude запись уже
правили (здесь или на другом устройстве), — тогда «Полка» так и скажет. Список — с последнего запуска
«Полки»; сами записи остаются на полке как обычные и уходят на другие устройства при обмене.

## Безопасность

- «Полка» ничего не открывает в интернет. Приложение Claude запускает `polka.exe --mcp`, а тот передаёт
  запросы запущенной «Полке» только внутри этого компьютера (127.0.0.1). Ключ связи «Полка» создаёт
  заново при каждом запуске и кладёт в свою папку данных; по сети он не ходит — стороны доказывают
  друг другу, что знают его. Программа, занявшая порт закрытой «Полки», не получит ни ключа, ни запроса.
- Claude видит только то, что запросит в разговоре по вашей просьбе, — это уходит в Anthropic вместе
  с разговором. Остальное остаётся на компьютере.
- Пока «Полка» заблокирована PIN-кодом, Claude ничего не получает: «Полка» открывает окно входа,
  а Claude просит вас войти.
- Запись выключена, пока вы её не разрешите; подключение целиком выключается одним переключателем.
  Переключатели у каждого компьютера свои.

## Ограничения

- Коннектор — в «Полке» на компьютере и в приложении Claude на этом же компьютере. Для claude.ai
  в браузере и на телефоне нужен удалённый коннектор со своим сервером — его пока нет. Записи, сделанные
  Claude на компьютере, приходят на телефон при обмене по Wi-Fi или через облако.
- Цитаты Claude только читает: цитата привязана к месту в файле книги, её сохраняют в читалке.

## Как устроено

- Ядро: `polka-core::mcp` — протокол MCP (JSON-RPC построчно через stdio), доказательство ключа связи
  (BLAKE2b-MAC от одноразовых чисел), файл расширения `.mcpb`; `polka-core::tools` — инструменты:
  чтение (`summary`, `shelf`, `title`, `stats`, `quotes`) и запись (`add_title`, `update_title`,
  `mark_episodes`, `delete_title`, `set_goal`). Запись только готовит новые значения вместе с прежними —
  для «Вернуть»; применяет их приложение.
- Приложение: `claude.rs` — посредник `polka --mcp` и приём его запросов на 127.0.0.1, переключатели,
  список действий, расширение. Второй запуск «Полки» открывает уже работающую (плагин single-instance) —
  им же пользуется посредник, если «Полка» закрыта.

## Что проверить

| Где | Что сделать | Что должно получиться |
|---|---|---|
| Компьютер | Обновить «Полку» до 0.10.0 поверх | Ставится, данные на месте |
| Компьютер | Настройки → Claude → включить подключение, «Установить в Claude» | Файл «Полка для Claude.mcpb» в «Загрузках», приложение Claude предлагает установить |
| Компьютер | Установить расширение в приложении Claude | «Полка» в списке расширений |
| Компьютер | Спросить Claude «Что я прочитал в этом году?» | Ответ совпадает с «Итогами» в «Полке» |
| Компьютер | Попросить добавить книгу при выключенной записи | Claude говорит, что запись выключена |
| Компьютер | Разрешить запись, попросить добавить книгу в «Хочу» | В «Полке» сообщение «Claude: Добавлено…» с «Вернуть», у записи обложка из каталога |
| Компьютер | Нажать «Вернуть» | Запись исчезла |
| Компьютер | Попросить отметить сезон сериала | Серии отмечены, статус «Смотрю» или «Просмотрено» |
| Компьютер | Закрыть «Полку» и спросить Claude о полке | «Полка» открывается сама, Claude отвечает |
| Компьютер | С PIN-кодом: заблокировать «Полку», спросить Claude | Открывается окно входа, Claude просит войти |
| Компьютер | Открыть «Полку» второй раз из меню «Пуск» | Открывается уже запущенное окно, второе не появляется |
| Телефон | Обмен после записи Claude | Запись пришла на телефон |

# Этап 6: поиск, «Поделиться» и картинка года (0.5.0)

## Поиск по полке

- В шапке полки — **лупа**: по нажатию выезжает поле, полка отбирается по мере набора — по названию
  (и оригинальному), автору, меткам и заметке. Регистр и «ё/е» не важны, слова запроса — в любом порядке.
- Что нашлось в списке «Хочу», показывается отдельно ниже. Крестик в поле очищает запрос, повторное нажатие
  на лупу убирает поле.

## Порядок и метки

- Кнопка рядом с лупой — выезжают теги: **«Автор»**, **«Жанр»**, **«Год»** и ваши метки (чаще встречающиеся
  первыми).
- Автор, жанр и год задают порядок полки: по фамилии первого автора, по жанру, по году выхода (новые
  первыми); у кого нет автора, жанра или года — в конце. Подпись под обложкой показывает то, по чему упорядочено.
- Метка оставляет только записи с ней. Повторное нажатие на тег снимает его.
- Выбор запоминается на устройстве; пока тег метки скрыт, над полкой видно «Только с меткой … · снять».

## «Поделиться» → «Полка» (Android)

- В Литресе, LiveLib, Кинопоиске или браузере: «Поделиться» → «Полка». Открывается добавление с найденной
  книгой или фильмом и выбором обложки; статус по умолчанию — «Хочу».
- Кинопоиск: номер фильма или сериала берётся из адреса, данные и постер — из ПоискКино (нужен ключ
  ПоискКино в настройках). Страницы Кинопоиска программе не отдаются, поэтому так.
- Если страница не открылась (сайт недоступен из вашей сети), «Полка» ищет по названию из текста, который
  прислало приложение, — например, «Брат» из «Посмотрите «Брат» на Кинопоиске».

## Картинка года

- «Итоги» → **«Картинка 2026 года»**: коллаж обложек за год (до 18, сначала с высокой оценкой; остальные —
  «+N»), сколько книг, фильмов и сериалов, страницы и часы, лучшее за год.
- Рисуется на устройстве из обложек в базе — интернет не нужен. Размер 1080 × 1350.
- Компьютер: «Сохранить…» — окно «Сохранить как», по умолчанию папка «Изображения».
  Телефон: «Поделиться» — отправить в мессенджер или сохранить.

## Что проверить

| Что | Как | Что должно получиться |
|---|---|---|
| Поиск | Лупа → «стругацк» | Остаются книги Стругацких; крестик возвращает всё |
| Поиск по метке и заметке | Лупа → слово из заметки или метки | Записи с ним; совпадения из «Хочу» — отдельно |
| Порядок | Кнопка порядка → «Автор», затем «Год» | Полка по фамилиям, затем по году выхода; подписи под обложками меняются |
| Метка | Тег метки → ещё раз | Только записи с меткой → снова все |
| Запоминание | Выбрать «Жанр» и метку, перезапустить «Полку» | Порядок и метка те же, над полкой «Только с меткой …» |
| «Поделиться» из браузера | Страница книги → «Поделиться» → «Полка» | Добавление с книгой и обложками, статус «Хочу» |
| «Поделиться» из Кинопоиска | Фильм → «Поделиться» → «Полка» | Добавление с фильмом и постером из ПоискКино |
| Сайт недоступен | Поделиться ссылкой на недоступный сайт с названием в тексте | Сообщение и поиск по названию |
| Картинка года | «Итоги» → «Картинка 2026 года» | Превью: обложки, цифры, лучшее за год |
| Сохранить (компьютер) | «Сохранить…» | Файл «Полка — итоги 2026.png» в выбранной папке |
| Поделиться (телефон) | «Поделиться» | Окно «Поделиться» с картинкой |

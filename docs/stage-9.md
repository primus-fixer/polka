# Этап 9: PDF и файлы книг на всех устройствах (0.8.0)

## PDF

- Открывается так же, как EPUB и FB2: **«Открыть файл книги»** в карточке, **«Добавить» → «Файл книги»**,
  перетаскиванием в окно на компьютере, **«Открыть с помощью» → «Полка»** или «Поделиться» на телефоне.
- Название и автор — из свойств файла (а если их нет — из имени файла). Служебное вроде
  «Microsoft Word - книга.docx» или «Admin» отбрасывается. **Обложка — первая страница** (если у записи
  её ещё не было). Число страниц записи — из файла.
- **Листать:** лентой (прокрутка, как в браузере) или по страницам — в «Виде страницы». Касание справа
  и слева листает на экран вперёд и назад, PageDown/PageUp и пробел — тоже, стрелки ← → — по страницам,
  Home/End — в начало и конец. Касание в середине — панели. По страницам: свайп влево и вправо.
- **Масштаб:** щипком на телефоне, Ctrl+колесо и Ctrl +/− на компьютере, кнопки − и + в «Виде страницы»;
  там же «Авто», «По ширине», «Страница целиком». Выбранный масштаб запоминается на этом устройстве.
- **Темы:** светлая, сепия (страницы теплее), тёмная (страницы в обратных цветах), «как в «Полке»».
  На широком экране — две страницы рядом.
- **Оглавление** — из файла (если оно там есть), с номерами страниц; переход на страницу по номеру.
  Ссылки внутри PDF работают, после перехода — «Назад». Внешние ссылки — в браузере.
- **Поиск по тексту:** без разницы «е» и «ё» и регистра, найденное подсвечено.
- **Закладки и цитаты** — как в EPUB: закладка на страницу, цитата из выделенного текста (подсвечивается),
  цитата картинкой. Место чтения, проценты, минуты в «Итогах» и место на других устройствах — тоже.
- **Сканы** (страницы-картинки без текста) читаются, но искать и выделять в них нечего — «Полка» так и скажет.
- PDF с паролем на открытие и с защитой DRM не открываются. PDF с запретом копирования (пароль
  владельца) открываются.

## Файлы книг на всех устройствах

- О каждом файле, открытом в читалке, теперь знают все ваши устройства: запись о нём уходит вместе
  с полкой. В карточке на другом устройстве видно: «Файл «…» (12 МБ) — на другом устройстве».
- Сами файлы переносятся там, где включено **Настройки → Файлы книг → «Файлы книг на всех устройствах»**.
  Переключатель свой у каждого устройства: включите там, где хотите читать (и там, где файлы лежат).
  Например, на компьютере и планшете включено, на телефоне — нет: телефону приходят только записи,
  место чтения, закладки и цитаты.
- **По Wi-Fi** — при обычном обмене, кусками по 8 МБ; оборвался — докачается с того же места.
  **Через облако** — зашифрованными кусками в папке «Полка/k»; файл забирается, когда другое устройство
  отправило его целиком. Готовый файл сверяется с отпечатком (SHA-256) — испорченный или подменённый
  не ляжет на место.
- Файлы, открытые до 0.8.0, попадают в общий список при первом запуске новой версии.
- **«Убрать с устройства»** в карточке удаляет файл только здесь (на других он остаётся) и больше
  не забирает его сюда сам. Передумали — **«Вернуть»** в карточке: файл придёт при следующем обмене.
- **В резервной копии** файлы книг — по своему переключателю (Настройки → Файлы книг, на компьютере):
  копия становится больше на их размер, зато восстанавливаются и записи, и книги. Копии без файлов
  открываются и в старых версиях; копии с файлами старые версии тоже читают — только без файлов.

## Как устроено

- PDF: в ядре (`polka-core::reader::pdf`) — только сведения для полки (lopdf: словарь Info без чтения
  всего файла, иначе XMP), в отдельном потоке — испорченный файл «Полку» не уронит. Страницы, текстовый
  слой, оглавление и поиск — pdf.js в интерфейсе; он загружается, только когда открывают PDF. Шрифты
  и таблицы для PDF без встроенных шрифтов лежат в приложении — интернет не нужен.
- Место в PDF: страница и доля её высоты; места цитат и найденного — знаки текста страницы, как у глав EPUB.
- Файлы книг (`polka-core::files`): запись журнала `file` (отпечаток, запись полки, имя, формат, размер).
  По Wi-Fi — новые сообщения обмена (с 0.8.0; со старыми версиями эта часть пропускается); в облаке —
  папка `k`, имя куска — MAC от отпечатка файла, номер куска и их число входят в проверку подлинности;
  в копии — новый вид записей, который старые версии пропускают.

## Что проверить

| Что | Как | Что должно получиться |
|---|---|---|
| PDF из карточки | Книга на полке → «Открыть файл книги» → `.pdf` | Читалка PDF; у записи без обложки — первая страница обложкой |
| PDF через «Добавить» | «Добавить» → «Файл книги» → `.pdf` | Запись «В процессе» с названием, автором и числом страниц из файла |
| PDF на телефоне | Файл в «Загрузках» → «Открыть с помощью» → «Полка» | PDF открылся |
| Листание | Касание справа/слева, PageDown, стрелки, колесо | Лентой — на экран; стрелки — на страницу |
| По страницам | «Аа» → «Листать: по страницам», свайп влево | Страница за страницей |
| Масштаб | Щипок на телефоне; Ctrl+колесо на компьютере | Страница крупнее, чётко перерисовывается |
| Тёмная тема | «Аа» → «Тёмная» | Страницы в обратных цветах |
| Оглавление | Середина → значок оглавления → раздел | Переход к разделу; «Назад» |
| Поиск | Лупа → слово | Список с номерами страниц; переход с подсветкой |
| Цитата | Выделить текст → «В цитаты» | Подсветка на странице; цитата в карточке |
| Закладка | Середина → значок закладки | Ленточка; в «Закладках» — «Стр. N» и начало текста |
| Место | Закрыть PDF и открыть снова | Та же страница; на другом устройстве — после обмена |
| Скан | PDF из сканов → поиск | «В этом PDF нет текста…» |
| Файл на другом устройстве | Открыть книгу на компьютере, обменяться с телефоном | В карточке на телефоне: «Файл … — на другом устройстве» |
| Файлы по Wi-Fi | Включить «Файлы книг на всех устройствах» на обоих → обмен | Файл пришёл, «Читать» открывает его |
| Файлы через облако | Включить на обоих, обменяться через облако на каждом | Файл пришёл со второго обмена (первый отправляет) |
| Убрать и вернуть | Карточка → «Убрать с устройства», обмен; потом «Вернуть», обмен | Убранный не приходит; после «Вернуть» — приходит |
| Копия с файлами | Компьютер: включить «Файлы книг в резервной копии» → «Сделать копию» | В копии «… файлов книг»; восстановление на другом устройстве кладёт файлы |

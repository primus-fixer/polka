# Этап 8: читалка книг (0.7.0)

## Как открыть книгу

- **Из карточки книги** — кнопка **«Открыть файл книги»**: книга привязывается к этой записи.
  Потом на её месте — **«Читать»** или **«Продолжить · 45 %»**.
- **«Добавить» → «Файл книги»**: «Полка» ищет книгу у себя — по ISBN, по названию и автору, по тому же
  файлу на другом устройстве. Не нашла — заводит запись «В процессе» с описанием, авторами, годом
  и обложкой из файла.
- **Компьютер:** файл можно просто перетащить в окно.
- **Телефон:** «Открыть с помощью → Полка» в файловом менеджере, загрузках браузера, Telegram;
  или «Поделиться» файлом.
- Форматы: **EPUB** (2 и 3) и **FB2** — в том числе `.fb2.zip` и старые FB2 в windows-1251.
  Книги с защитой (DRM) и PDF не открываются.
- Открыть книгу «Хочу» — значит начать: запись становится «В процессе» с сегодняшней датой.

## Чтение

- Страница — как в книге: колонка текста, листание касанием по краю (слева — назад, справа — вперёд),
  свайпом, колесом мыши, стрелками, PageUp/PageDown и пробелом. Касание в середине — панели.
- На широком экране — **две страницы рядом** (выключается в «Виде страницы»).
- Внизу всегда: глава и «страница / всего · процент книги».
- Панели: **оглавление**, **поиск по книге** (без разницы «е» и «ё» и регистра; найденное подсвечено),
  **вид страницы**, ползунок по всей книге, «осталось около …» — по вашей скорости чтения
  (она считается на этом устройстве сама).
- **Сноски** открываются окошком поверх страницы; «Перейти к сноске» — к самой сноске. После перехода
  по ссылке или оглавлению появляется **«Назад»** — на прежнее место.
- **Вид страницы:** размер шрифта, шрифт с засечками (Literata) или без (Golos), интервал, поля,
  тема (как в «Полке», светлая, сепия, тёмная), выравнивание по ширине или по левому краю, переносы.
  Запоминается на этом устройстве.
- **Конец книги:** «Отметить «Прочитано»» и оценка — прямо в читалке.
- Пока книга открыта, экран не гаснет (где система это позволяет).

## Место чтения на всех устройствах

- Место запоминается после каждого листания на этом устройстве, а в журнал — раз в пару минут,
  при выходе из книги и когда «Полка» уходит в фон. По Wi-Fi и через облако оно уходит на другие
  устройства, как полка.
- На другом устройстве **тот же файл** открывается на той же странице (с подсказкой «Продолжаем с места,
  где читали на другом устройстве»). Другой файл той же книги (другое издание) — примерно на том же
  проценте.
- **Файлы книг между устройствами не ходят**: на телефоне книгу открывают там же, из карточки
  («Открыть файл книги»). В карточке видно «прочитано 45 % · файл — на другом устройстве».
- Время за чтением копится в записи о чтении (для будущих «Итогов»).
- На полке в блоке «Сейчас» у книги с файлом — процент, полоска и кнопка **«Читать»**.
- «Убрать с устройства» в карточке (строка «Файл книги») удаляет только файл: запись и место остаются.

## Как устроено

- Ядро (`polka-core::reader`) открывает книгу целиком из файла: архив EPUB читается в памяти, на диск
  ничего не распаковывается. Разметка разбирается терпимо: книги с ошибками и с сущностями HTML
  (`&nbsp;`) открываются.
- Главы приходят на экран не разметкой, а деревом из разрешённых тегов и атрибутов; страница строит его
  сама (`createElement`), скрипты, формы, iframe и обработчики событий из книги не доходят до экрана.
  Из стилей книги берётся только смысл: курсив, жирный, выравнивание, отступы стихов, разрывы страниц.
- Очень большие главы (книга одним файлом) делятся на части — ссылки и оглавление ведут куда надо.
- Картинки книги отдаёт протокол `book` приложения — только картинки и только из открытых книг.
- Файлы книг — в папке данных приложения (`books/`); какая книга к какой записи — в местных настройках
  базы. Место чтения — запись журнала `reading` (номер записи полки, хеш файла, глава, знак, процент).

## Что проверить

| Что | Как | Что должно получиться |
|---|---|---|
| EPUB из карточки | Книга на полке → «Открыть файл книги» → `.epub` | Читалка открылась на начале; в карточке — «Читать» |
| FB2 через «Добавить» | «Добавить» → «Файл книги» → `.fb2` (или `.fb2.zip`) | Запись «В процессе» с обложкой из файла, читалка открыта |
| Старый FB2 | FB2 в windows-1251 | Кириллица читается, не «кракозябры» |
| Перетащить | Компьютер: файл книги в окно «Полки» | Книга открылась |
| Открыть с помощью | Телефон: файл в «Загрузках» → «Открыть с помощью» → «Полка» | Книга открылась |
| Листание | Касание справа/слева, свайп, стрелки, колесо | Страницы листаются, на краю главы — следующая |
| Оглавление | Середина → значок оглавления → глава | Переход; внизу «Назад» |
| Поиск | Середина → лупа → слово | Список мест; нажатие — страница с подсветкой |
| Сноска | Нажать на номер сноски в тексте | Окошко со сноской |
| Вид | «Аа» → крупнее, сепия, без засечек | Страница перестроилась на том же месте |
| Две страницы | Компьютер, окно шире 900 точек | Два столбца рядом |
| Место на другом устройстве | Почитать на компьютере, обменяться, открыть тот же файл на телефоне | «Продолжаем с места…», та же страница |
| Конец | Долистать до конца | «Конец книги»: «Отметить «Прочитано»», оценка |
| Убрать файл | Карточка → «Файл книги» → «Убрать с устройства» | Кнопка снова «Открыть файл книги», процент остался |
